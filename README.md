# Utensils: A C Algorithm and Data Structure Library

utensils is a C algorithm and data structure library aiming to provide a set of high-performance basic algorithms and data structures for developers to call in their own projects.

Supported: Balanced Search Trees (bst)
In progress: Basic Linear Algebra Subprograms (BLAS)

## Usage

### Compile

In the root directory, run

```bash
make
```

to build the library. Output file ```libutensils.a``` is under ```/lib```.

### Demo

After building the library successfully and set the link path correctly, you can run demos under ```/example```.

### benchmarks

After building the library successfully and set the link path correctly, you can run bemchmarks under ```/benchmarks```. Now it supports comparing to C++'s Standard Template Library (C++ STL).
